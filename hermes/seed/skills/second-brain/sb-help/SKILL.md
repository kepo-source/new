# sb-help

Jawab dengan daftar perintah ini, ringkas dalam Bahasa Indonesia:

- `/second-brain` — bundel semua skill second-brain
- `/sb-ask <teks>` — tanya dengan model utama (auto fallback)
- `/sb-fast <teks>` — jawab cepat, model `mistralai/mistral-medium-3.5`
- `/sb-deep <teks>` — analisis lebih dalam dan terstruktur
- `/sb-banding <teks>` — bandingkan dua sudut pandang/model
- `/sb-stats` — pemakaian & biaya hari ini dari Google Sheet
- `/sb-budget` — sisa budget harian
- `/sb-model` — provider/model aktif dan urutan fallback
- `/sb-reset` — mulai sesi baru (konteks dihapus)

Tambahkan: pesan teks biasa juga diproses seperti `/sb-ask`.
Jangan menyebut detail internal (path file, API key, token).
