# sb-reset

Mulai sesi baru dengan menjalankan perintah gateway `/reset` (atau `/new` kalau tersedia).
Setelah itu balas singkat:

```
🧹 Konteks dihapus. Mulai dari nol.
```

Jangan menghapus file, config, atau data Sheets. Jangan keluar dari skill ini dengan penjelasan panjang.
